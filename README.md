## Sobre mí

Soy Técnico Universitario en Programación recibido de la Universidad Tecnológica Nacional (UTN). Me dedico de lleno al diseño y construcción de plataformas web escalables, con un foco absoluto en el ecosistema Frontend moderno y arquitecturas Full-Stack.

No creo en el código porque sí; mi prioridad es la calidad del producto final. Trabajo asegurando un tipado estricto, reactividad pura y experiencias de usuario (UI/UX) fluidas a 60 FPS pensadas para producción.

- **Foco principal:** Desarrollo de interfaces reactivas y robustas utilizando **Angular 19** y **React**.
- **Backend & Seguridad:** Modelado de bases de datos relacionales, autenticación y políticas estrictas de seguridad (RLS) con **Supabase**.
- **Filosofía de trabajo:** Clean Code, arquitecturas Standalone y diseño "Mobile-First".

## Proyectos Estrella

### [Healix (SaaS Clínico)](https://github.com/ErikLujan/ruta-a-tu-repo-healix)
Plataforma médica B2B moderna y escalable para la gestión integral de centros de salud[cite: 23]. Desarrollada como un portfolio profesional de nivel senior[cite: 23].
- **Arquitectura:** Motor complejo de turnos, historias clínicas dinámicas y sistema de autenticación multi-rol (Pacientes, Especialistas y Admins)[cite: 23].
- **Seguridad:** Control de acceso estricto (RBAC) amparado por políticas de Row Level Security (RLS) en la base de datos[cite: 23].
- **Stack:** Angular 19 (Standalone Components, Signals, New Control Flow), Tailwind CSS v4, Supabase (Auth, PostgreSQL, Storage) y Lucide Angular[cite: 23].

### [ChromaForge](https://github.com/ErikLujan/chromaforge)
Generador interactivo de paletas de colores diseñado para creadores y desarrolladores. Una herramienta visual enfocada en la estética y la experiencia de usuario.
- **Arquitectura:** Generación algorítmica de esquemas de color, previsualización en tiempo real y exportación de variables CSS/Tailwind.
- **Stack:** React, Tailwind CSS.

## Ecosistema Backend & Automatización

Aunque hoy mi foco de diseño y arquitectura pasa por el Frontend, tengo una base técnica pesada armando APIs, pipelines de datos y sistemas distribuidos. Acá están los proyectos que respaldan esa experiencia:

| Proyecto | Descripción | Stack |
| :--- | :--- | :--- |
| **[Task Queue System](https://github.com/ErikLujan/Task-Queue-System)** | Arquitectura distribuida para procesamiento asíncrono. Motor orquestado con FastAPI y Celery para manejar colas de trabajos pesados (imágenes, reportes). Incluye migraciones con Alembic, webhooks, Rate Limiting y monitoreo con Prometheus. | `Python`, `FastAPI`, `Celery`, `Docker`, `Prometheus` |
| **[Tech Job Reporter](https://github.com/ErikLujan/tech-job-reporter)** | Pipeline ETL 100% automatizado mediante GitHub Actions. Un proceso que extrae ofertas laborales, las evalúa integrando un cliente de IA, renderiza reportes en formato PDF y los distribuye automáticamente por correo. | `Python`, `GitHub Actions`, `AI / LLM`, `PostgreSQL` |
